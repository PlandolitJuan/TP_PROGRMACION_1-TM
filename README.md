# TP_PROGRMACION_1-TM-1

Con este proyecto quisimos recrear cómo sería el programa de una agencia de alquiler de autos. Al ejecutarlo, el programa nos dará la bienvenida y automáticamente se nos mostrará un menú en donde podremos acceder a distintas opciones. El objetivo del programa es tener organizados los datos de todos los autos con los que cuenta la agencia en archivos de texto. Luego de ejecutada la opción deseada, el programa volverá al menú. Este ciclo se repetirá hasta que el usuario ingrese la opción número 6, la cual le da fin a la ejecución.
